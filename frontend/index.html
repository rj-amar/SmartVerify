Statutory Verification Workflow

End-to-end digital lifecycle conforming to Legal Metrology General Rules

1

Register Instrument

Enter instrument technical details; backend atomically generates permanent sequential serial (e.g. OVS-000001).

2

Apply for Verification

5-step application referencing database ID with precise installation address and inspection district.

3

Upload Documents

Upload previous calibration certificates, invoices, or identity proof with strict 5MB server validation.

4

District Assignment

System automatically identifies active officers in the same district and assigns officer with lowest workload.

5

Inspection Scheduling

Officer schedules date and location; persistent notifications notify applicant immediately.

6

Digital Field Test

Officer enters test point readings in native units; automatic error calculations evaluate PASS/FAIL tolerances.

7

Digital Certificate

Officer approves verification; PDFKit generates official high-resolution statutory certificate with security hash.

8

Public QR Verification

Anyone can scan the certificate QR code or search publicly to verify real-time statutory status without login.
